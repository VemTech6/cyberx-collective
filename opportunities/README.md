Every posting is a repo **Issue**, not a line in a doc someone forgets to update. That means you can filter, sort by label, and get notified — and it means postings can be closed the moment they expire instead of lingering as a dead link.

> [!NOTE]
> This repo's Issues tab is shared across all of CyberX Collective — opportunity postings sit alongside any other issue, so always filter by label rather than browsing the full list.

<a id="-how-postings-work"></a>
## 💼 How Postings Work

Go to the **[Issues tab](https://github.com/VemTech6/cyberx-collective/issues)** and filter by an opportunity label (below) — every matching open issue is a live posting listing the role, org, location, deadline, eligibility, and a direct application link.

> [!NOTE]
> An issue getting closed doesn't mean the pipeline is gone for good — many of these (SFS, Stokes, SMART, CIA, DHS HS-POWER) run on annual cycles. Closed issues stay in the repo as a record of when the last cycle ran.

<a id="-labels"></a>
## 🏷️ Labels

Filter the Issues tab by label to find what applies to you:

| Label | Meaning |
|---|---|
| `internship` | Internship-length position |
| `full-time` | Post-graduation role |
| `co-op` | Alternating semester work/study |
| `scholarship` | Funding tied to a service or academic commitment |
| `deadline-soon` | Applications close within ~30 days |
| `remote` | No relocation required |
| `clearance-required` | Requires (or sponsors) a security clearance |
| `no-experience-needed` | Open to students with no prior professional cyber experience |

> [!TIP]
> `no-experience-needed` + `scholarship` is the fastest filter for a first-year member wondering "can I even apply to any of these yet?" Usually yes.

<a id="-submit-one"></a>
## 📄 Submit One

Found a posting we're missing? Open an issue using the **opportunity template** (New Issue → "New opportunity posting") — it asks for role, org, location, deadline, eligibility, and a link. Double-check the link and deadline are current before you submit; a dead link here is worse than no posting at all.
